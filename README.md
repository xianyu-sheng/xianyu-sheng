## About me

I build practical AI agents and developer tools, with a focus on reliable tool use, multi-agent orchestration, and workflows that turn model capabilities into repeatable engineering results.

重庆邮电大学学生，关注 **AI Agent、代码智能、MCP 与开发者工具工程化**。喜欢把想法做成可以运行、测试、复现的开源项目。

- 🔭 Currently building agent infrastructure and coding assistants
- 🧪 Interested in evaluation, reproducibility, and human-friendly developer experiences
- 🌏 Based in Chongqing, China
- 💬 Open to interesting ideas around LLM agents and open source
